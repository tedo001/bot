# Workcell

The Run workspace assembled from the components at 1280 × 800: ribbon with E-STOP, cell browser and properties on the left, viewport and console in the centre, instruction, run controls, task plan and collapsed telemetry on the right, status bar along the bottom.

Use it as the reference layout for every workspace; swap the docks' panels per the Screens section. Press the ribbon's E-STOP (or `Esc`) in the preview to see the latch: the banner appears, the episode becomes STOPPED, and Run, Step, Jog and Home stay disabled until release.
